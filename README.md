# KRUTZ Restaurant OS

KRUTZ is a restaurant operating system with:

- 3D AR Food Menu
- QR Table Ordering
- Voice Ordering
- Checkout
- Live Order Tracking
- Kitchen Dashboard
- Waiter Dashboard
- Cashier Billing
- Manager Dashboard
- Owner Analytics
- Inventory
- Reservations
- Customer Requests
- Sound/Vibration Alerts
- WhatsApp Bot MVP

## Demo Flow

Customer scans QR → Orders food → Kitchen receives order → Waiter serves → Cashier collects payment → Owner sees analytics.
